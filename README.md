# Claude-Talk

A playground for trying out what Claude Code can do with our tools — Google Chat, Calendar, GitHub and more.

## Workflow

- Work happens on feature branches (e.g. `first-branch`).
- Every push is shared with the reviewer on Google Chat along with a link to the changes and a short summary.

## Getting started

```bash
git clone https://github.com/arpithkdev-sketch/Claude-Talk.git
cd Claude-Talk
git switch first-branch
```
